## Installation

> [!CAUTION]
> This is still VERY experimental and shouldn't be relied on! <br>
> Expect bugs and security issues!

As of writing this, currently only Linux and iOS are supported. See below for install instructions.

### Linux

For stable releases, download latest good snapshot from "Releases" tab. For bleeding-edge, clone this repository.

Then, run this in your terminal:

`./scripts/install.sh`

### iOS

For stable releases, download latest good .ipa from "Releases" tab. For bleeding-edge, download latest build from "Actions" tab (GitHub account required).

Then, install it with any sideloader (AltStore Classic, SideStore, Sideloadly, Feather, etc.)
